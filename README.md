# JavaScript Problem-Solving Practice

A repository containing basic to intermediate JavaScript programming problem solutions. This repo covers fundamental concepts like unit conversion, array operations, math methods, logic building, and object manipulation.

## 📁 Repository Overview

Here is a quick summary of the problems solved in this repository:

* **`problem01.js` & `problem2.js`**: Unit conversion and average calculation logic for even numbers.
* **`problem3.js`**: String array structuring for managing student lists.
* **`problem4.js`**: Exploration and practical usage of the JavaScript `Math` object.
* **`problem5.js`**: Swapping values using temporary variables and destructuring assignment.
* **`problem6.js`**: Finding the maximum score using multiple approaches.
* **`problem7.js`**: Finding the minimum number from an array.
* **`problem8.js`**: Multi-layer discount calculation logic.
* **`problem9.js`**: Finding the cheapest phone from an array of phone objects.
* **`problem10.js`**: Temperature conversion program (Celsius to Fahrenheit).
